# comfyui-Reference_image

独立的 ComfyUI 参考图创作节点。安装到 `ComfyUI/custom_nodes/comfyui-Reference_image` 后重启 ComfyUI，在画布搜索 **参考图创作台**。

节点按 **脸模 → 场景 → 服装 → 姿势** 排列四张卡片。上方可随机组合或更新提示词，每张图库卡片也可单独随机；中间可选图库素材、上传图片、查看大图或清除；下方显示整合提示词并可复制。创作需求、场景图用途和姿势选项在“创作设置”中。场景卡片支持上传图片。选择和上传只改变本节点，不自动运行工作流。上传图片保存在 ComfyUI 的 `input/reference-image`。

本地图库放在插件内的 `resources/face-gallery`、`resources/costume-gallery`、`resources/pose-gallery`。节点优先从本插件读取这些目录。若没有这些目录，仍可上传图片使用。

点击“更新提示词”可预览整合后的文字；运行工作流时，后端使用同一套提示词逻辑。节点输出最终提示词、IMAGE 列表、参考图编号说明，以及脸模、场景、服装、姿势四个独立的 IMAGE 接口。旧版前三个输出保持原位，现有工作流连接无需改动。独立图片接口可分别接到下游生图节点对应的图片输入；未选择的类别输出为空，请只连接已经选择的图片。参考图列表按实际选择的脸模、场景、服装、姿势排序，仅连接支持 IMAGE 列表的下游节点。**这个节点与“无限模特孵化器”都是参考图输出节点，不能直接互连。** 此节点不内置生图服务。

图库素材体积约 4 GB，且具有独立授权条件，因此 GitHub 仓库只包含代码，本地素材目录被 Git 忽略；请保留素材目录中的来源和许可说明。
