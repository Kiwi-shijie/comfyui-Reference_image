# comfyui-Reference_image（角色创作台）

将本文件夹复制到 ComfyUI 的 custom_nodes，重启 ComfyUI，搜索“角色创作台”。这是独立插件，不修改原有节点或素材。

将已有的脸模、姿势、服装素材节点 IMAGE 输出，分别连接到本节点的对应输入；场景和人物也可以使用 Load Image。姿势节点的说明可以连接到“上游姿势说明”。节点依次输出人物、场景、姿势、服装中实际连接的图，并在提示词和顺序说明中使用 <image1> 等编号。

“参考图列表”是 ComfyUI 的 IMAGE 列表，不是合并的 IMAGE 批次。只有支持列表输入并按顺序使用多张独立参考图的下游节点才能直接使用；不同生图节点的图像引用语法可能不同，需按实际节点调整。列表为空时用于文生图。也可以把相同素材节点直接连接到下游的多个图片输入，确保顺序与提示词一致。

本节点负责整理提示词及参考图，不内置生图模型，不提供截图中的一体化预览、生成设置和下载界面。请连接已有的图像生成节点及 Preview Image 或 Save Image。素材由原插件提供，无需复制资源，素材选择界面仍使用原插件节点。
