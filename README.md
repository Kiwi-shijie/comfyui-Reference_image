# comfyui-Reference_image

独立的 ComfyUI 参考图创作节点。安装到 `ComfyUI/custom_nodes/comfyui-Reference_image` 后重启 ComfyUI，在画布搜索 **参考图创作台**。

节点按 **脸模 → 场景 → 服装 → 姿势** 排列四张卡片。上方可随机组合或更新提示词，每张图库卡片也可单独随机；中间可选图库素材、上传图片、查看大图或清除；下方显示整合提示词并可复制。创作需求、场景图用途和姿势选项在“创作设置”中。场景卡片支持上传图片。选择和上传只改变本节点，不自动运行工作流。上传图片保存在 ComfyUI 的 `input/reference-image`。

四张卡片都支持把本地图片直接拖入上传；也可先点击目标卡片，再按 `Ctrl+V` 粘贴剪贴板图片。支持 PNG、JPG 和 WEBP，单张不超过 30 MB。素材库会随滚动继续加载，直至浏览全部素材；搜索可筛选，卡片上的放大镜可在选用前查看大图。

本地图库放在插件内的 `resources/face-gallery`、`resources/costume-gallery`、`resources/pose-gallery`。节点优先从本插件读取这些目录。若没有这些目录，仍可上传图片使用。

点击“更新提示词”可预览整合后的文字；运行工作流时，后端使用同一套提示词逻辑。节点输出最终提示词、IMAGE 列表、参考图编号说明，以及脸模、场景、服装、姿势四个独立的 IMAGE 接口。旧版前三个输出保持原位，现有工作流连接无需改动。独立图片接口可分别接到下游生图节点对应的图片输入；未选择的类别输出为空，请只连接已经选择的图片。参考图列表按实际选择的脸模、场景、服装、姿势排序，仅连接支持 IMAGE 列表的下游节点。**这个节点与“无限模特孵化器”都是参考图输出节点，不能直接互连。** 此节点不内置生图服务。

图库素材体积约 4 GB，且具有独立授权条件，因此 GitHub 仓库只包含代码，本地素材目录被 Git 忽略；请保留素材目录中的来源和许可说明。

场景参考会在整合提示词中约束人物与背景的光照方向、色温、自阴影和脚下接触阴影。优先选择同时含有地面与明确主光的场景图；只有墙面光斑的图片难以提供人物落地位置与完整的光照信息。若一次生成仍有明显贴图感，可对人物和接触区域进行局部重绘，让背景光重新作用到人物，而不是只改全图提示词。

如果服装图是完整模特照，模特站姿可能压过姿势参考。可在“创作设置”中启用“姿势优先”，让整合提示词强调姿态和裁切。参考图编号始终按脸模、场景、服装、姿势排列；启用姿势优先不会更改接口顺序。统一控制工作流把姿势图接到提示词优化器和 ControlNet，Qwen 生图编码器只接脸模、场景和服装。不要把姿势线稿接到 Qwen 编码器的任何图片输入，否则模型可能把线稿画进结果。

使用视觉提示词优化器时，优化器的四个图像输入按脸模、场景、服装、姿势的顺序连接；优化后的文字经“姿势控制提示词”节点转换后接到生图编码节点。转换节点会把指向姿势参考的 `<image4>` 标记改成“姿势控制图”，防止生图编码器误把不存在的第 4 张编码参考当作编辑源。优化器仍会在每次换图后重新描述姿势；节点内手动填写的“姿势补充说明”会在更换姿势图时自动清除。

半身、蜷坐、强透视等特殊姿势，应让最终画幅尽量接近姿势图画幅。例如 600×800 的姿势图优先尝试 3:4，而不是强行输出 9:16 全身图。Qwen 编码节点会把 `image_01` 当作主要编辑参考；统一工作流另外使用本节点输出的空白潜空间作为采样起点，避免直接从姿势线稿的潜空间生成。ControlNet 会加强结构约束，但不能保证每个关节都精确一致。

“创作设置”中的“构图范围”默认为“自动跟随姿势”。图库里的“上半身单人”姿势会自动加入头到腰部的半身构图约束；其他单人姿势按全身处理。上传姿势图没有图库分类，可手动选择“半身”或“全身”。旧工作流仍需在下游比例节点中手动匹配输出画幅；下方的统一工作流会自动使用姿势图画幅。

`examples/Qwen2.1统一姿势控制.json` 是半身、全身和特殊姿势共用的一份工作流。导入后先在参考图创作台选择素材。它把姿势图接到 Qwen Image 2.1 Fun ControlNet 作为结构控制，把节点计算出的“姿势画幅宽/高”接到生图编码节点，并把“空白生成画布”接到采样器的 `latent_image`。VAE 解码结果直接送保存节点，不再按脸模照片的尺寸裁切生成画面。实测当前线稿素材在 ControlNet 强度 0.5 下可以生成真人照片；更高强度可能把线稿轮廓带回成图。更换姿势图后，构图提示词、控制图和画幅随之更新，无须切换工作流。示例使用本机已安装的 Qwen 图像编码与视觉提示词优化节点；其他环境需安装相应节点，并从 [Comfy-Org 官方模型仓库](https://huggingface.co/Comfy-Org/Qwen-Image-2.1/blob/main/model_patches/qwen_image_2.1_fun_controlnet_union_int8_convrot.safetensors) 下载 `qwen_image_2.1_fun_controlnet_union_int8_convrot.safetensors` 到 `ComfyUI/models/model_patches/`。模型文件不包含在本仓库。图库线稿可作为结构参考；要更精确地对齐关节，宜使用清晰的人体姿势控制图。
