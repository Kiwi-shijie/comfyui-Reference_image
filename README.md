# comfyui-Reference_image

独立的 ComfyUI 参考图创作节点。安装到 `ComfyUI/custom_nodes/comfyui-Reference_image` 后重启 ComfyUI，在画布搜索 **参考图创作台**。

节点按 **脸模 → 场景 → 服装 → 姿势** 排列四张卡片。上方可随机组合或更新提示词，每张图库卡片也可单独随机；中间可选图库素材、上传图片、查看大图或清除；下方显示整合提示词并可复制。创作需求、场景图用途和姿势选项在“创作设置”中。场景卡片支持上传图片。选择和上传只改变本节点，不自动运行工作流。上传图片保存在 ComfyUI 的 `input/reference-image`。

四张卡片都支持把本地图片直接拖入上传；也可先点击目标卡片，再按 `Ctrl+V` 粘贴剪贴板图片。支持 PNG、JPG 和 WEBP，单张不超过 30 MB。素材库会随滚动继续加载，直至浏览全部素材；搜索可筛选，卡片上的放大镜可在选用前查看大图。

本地图库放在插件内的 `resources/face-gallery`、`resources/costume-gallery`、`resources/pose-gallery`。节点优先从本插件读取这些目录。若没有这些目录，仍可上传图片使用。

点击“更新提示词”可预览整合后的文字；运行工作流时，后端使用同一套提示词逻辑。节点输出最终提示词、IMAGE 列表、参考图编号说明，以及脸模、场景、服装、姿势四个独立的 IMAGE 接口。旧版前三个输出保持原位，现有工作流连接无需改动。独立图片接口可分别接到下游生图节点对应的图片输入；未选择的类别输出为空，请只连接已经选择的图片。参考图列表按实际选择的脸模、场景、服装、姿势排序，仅连接支持 IMAGE 列表的下游节点。**这个节点与“无限模特孵化器”都是参考图输出节点，不能直接互连。** 此节点不内置生图服务。

图库素材体积约 4 GB，且具有独立授权条件，因此 GitHub 仓库只包含代码，本地素材目录被 Git 忽略；请保留素材目录中的来源和许可说明。

场景参考会在整合提示词中约束人物与背景的光照方向、色温、自阴影和脚下接触阴影。优先选择同时含有地面与明确主光的场景图；只有墙面光斑的图片难以提供人物落地位置与完整的光照信息。若一次生成仍有明显贴图感，可对人物和接触区域进行局部重绘，让背景光重新作用到人物，而不是只改全图提示词。

如果服装图是完整模特照，模特站姿可能压过姿势线稿。可在“创作设置”中启用“姿势优先”，并将下游生图编码节点的图片口改为 `image_01=姿势`、`image_02=脸模`、`image_03=场景`、`image_04=服装`。整合提示词及参考图列表会同步按这个顺序编号；四个独立 IMAGE 输出的标签和位置不变。建议在“姿势补充说明”中写明手臂、手、躯干和双腿的位置。多图参考和文字提示仍不能保证像骨架控制模型一样严格锁定关节。

使用视觉提示词优化器时，优化器的四个图像输入也必须按同样的顺序连接，并将优化器的 `prompt` 输出接到生图编码节点的 `prompt` 输入。这样优化器会在每次换图后读取当前姿势图；不要在工作流中保存固定的旧姿势说明。节点内手动填写的“姿势补充说明”会在更换姿势素材或上传新姿势图时自动清除。

半身、蜷坐、强透视等特殊姿势，应让最终画幅尽量接近姿势图画幅。例如 600×800 的姿势图优先尝试 3:4，而不是强行输出 9:16 全身图。Qwen 编码节点把 `image_01` 当作主要编辑画布；当它的宽高比与输出差距过大时，结构参照会变弱。若需要对关节做像素级控制，还需要适配该生图模型的姿势控制方案，文字和多图参考只能提高倾向，不能严格锁定每个关节。

“创作设置”中的“构图范围”默认为“自动跟随姿势”。图库里的“上半身单人”姿势会自动加入头到腰部的半身构图约束；其他单人姿势按全身处理。上传姿势图没有图库分类，可手动选择“半身”或“全身”。这个设置控制提示词，输出画幅还应在下游比例节点中匹配（半身优先试 3:4 或 4:5）。
